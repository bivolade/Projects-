## 🤖 AI & Machine Learning for Cybersecurity

A machine learning project investigating whether network traffic patterns could be used to identify attacks and predict session duration.

### Models Used

- Decision Tree Classifier
- Naive Bayes
- Linear Regression
- Decision Tree Regressor

### Feature Engineering

I created security-focused features including:

- `failed_login_rate`
- `bytes_per_packet`

The `failed_login_rate` feature proved useful during feature importance analysis. :contentReference[oaicite:2]{index=2}

### Key Findings

The Decision Tree achieved **32% recall on attack traffic**, compared with **10% for Naive Bayes**. This highlighted the importance of evaluating security models using metrics such as recall rather than relying solely on accuracy. :contentReference[oaicite:3]{index=3}

The analysis also identified `anomaly_score` as the most important feature, followed by `bytes_received` and `bytes_per_packet`. :contentReference[oaicite:4]{index=4}
