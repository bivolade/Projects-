### 1. AWS Cloud Infrastructure & Security — WinLocal Giveaways

**[View AWS Cloud Infrastructure Project](AWS-Cloud-Infrastructure/)**

**Technologies:** AWS, EC2, VPC, RDS MySQL, S3, Application Load Balancer, Auto Scaling, Linux, Apache, PHP

Designed and implemented a secure cloud infrastructure for a fictional organisation using Amazon Web Services.

**Key Features:**

- Configured a bastion host for secure administrative access.
- Deployed EC2 web servers behind an Application Load Balancer.

- Configured a private Amazon RDS MySQL database.
- Created an Amazon S3 static backup website.
- Applied security group rules to restrict network access.
- Investigated AWS WAF and GuardDuty as potential security improvements.

**Skills Demonstrated:** Cloud Security, Network Architecture, Access Control, AWS Infrastructure, Troubleshooting and Technical Documentation.

### 2. Web Application Penetration Testing & Vulnerability Assessment

**[View Web Application Security Project](Web-App-Penetration-Testing/)**

**Technologies:** Chrome Developer Tools, HTML, JavaScript, OWASP, CWE, OSINT

Conducted a security assessment of a deliberately vulnerable web application, focusing on authentication weaknesses and insecure password recovery mechanisms.

**Key Findings:**
- Identified exposed authentication information within client-side source code.
- Investigated a hardcoded credentials vulnerability (CWE-798).
- Demonstrated weaknesses in a security-question-based password recovery mechanism (CWE-640).
- Used manual reconnaissance and OSINT techniques to investigate publicly available information.
- Assessed the potential impact of unauthorised account access.
- Documented security findings and recommended remediation measures.

**Skills Demonstrated:** Web Application Security, Vulnerability Assessment, Authentication Security, OSINT, Risk Analysis and Security Reporting.

All testing was conducted within an authorised educational environment.

### 3. CyberTriageTool — Digital Forensics & Incident Response

**[View CyberTriageTool Project](CyberTriageTool/)**

**Technologies:** Python, PowerShell, VirusTotal API, SHA-256, JSON, Windows Registry, TCP Sockets

Developed a modular security investigation tool designed to assist with initial host triage and incident response activities.

**Key Features:**
- Automated collection of Windows process and network connection information.
- Modular Python plugin architecture.
- SHA-256 file hashing and VirusTotal threat intelligence lookups.
- Authentication log analysis for failed login activity.
- TCP port scanning functionality.
- IP address geolocation analysis.
- Windows Registry Run key examination.
- JSON-based configuration and data handling.

**Skills Demonstrated:** Digital Forensics, Incident Response, Python, PowerShell, Security Automation, Network Analysis and Threat Intelligence.

The project demonstrates how scripting can support initial cybersecurity investigations and reduce repetitive manual analysis.

### 4. Machine Learning for Cybersecurity — Network Attack Detection

**[View Machine Learning Project](Machine-Learning-Cybersecurity/)**

**Technologies:** Python, Jupyter Notebook, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

Developed and evaluated machine learning models to analyse network traffic data, classify potentially malicious activity and predict network session duration.

**Key Features:**
- Analysed a dataset containing 6,000 network session records.
- Performed exploratory data analysis and data cleaning.
- Applied feature engineering to network traffic data.
- Implemented Decision Tree and Gaussian Naive Bayes classification models.
- Compared model performance using accuracy, F1-scores and confusion matrices.
- Implemented Linear Regression and Decision Tree Regression for session duration prediction.
- Evaluated regression models using MAE, RMSE and R².
- Investigated feature importance and model limitations.

**Skills Demonstrated:** Python Programming, Machine Learning, Data Analysis, Feature Engineering, Model Evaluation and Cybersecurity Analytics.
